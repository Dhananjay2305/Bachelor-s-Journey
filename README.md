


# 🏠 BachelorHub — The Ultimate Bachelor Survival Guide

BachelorHub is a web application designed to help bachelors manage their daily life easily.  
It provides quick recipes, budget planning tools, and a live grocery shop — all in one platform.

## 🚀 Features

### 🍳 1. Bachelor-Friendly Recipes
- Category-based filtering (Breakfast, Lunch, Dinner, Snacks)
- Fast 15-minute meals
- Dynamic recipe loading from server
- Modal-based recipe view

### 💰 2. Smart Budget Manager
- Monthly budget input
- Custom percentage sliders (Rent, Food, Utilities, etc.)
- Real-time pie chart visualization
- Budget saving with server persistence (MongoDB)
- Budget history tracking
- Smart financial tips based on budget range

### 🛒 3. Live Grocery Shop
- Product search functionality
- Category filtering (Vegetables, Fruits, Dairy, Staples)
- Add to cart system
- Real-time cart calculation
- Delivery and total calculation
- Order persistence

### 💡 4. Survival Tips Section
- Practical life tips for bachelors
- Cleaning routines
- Electricity saving guidance
- Meal preparation strategies



## 🛠️ Tech Stack

- HTML
- CSS (Custom UI Styling)
- JavaScript (Vanilla JS)
- Canvas API (Pie Chart)
- REST API Integration
- MongoDB (for persistence)
